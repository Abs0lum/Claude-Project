# TINY-MOBS CENSUS — 2026-10-02 (read-only)

**Ruling being prepared (Abs0lum, verbatim):** "ALL TINY MOBS are not enemies. We can make BIG versions of them to follow hostile scripts, but the small ones are there for realism. Big ants, big scorpions, big beetles - or whatever else that is small and can be hostile - I want the small versions to be neutral or friendly; mostly there for observation, but we can make much larger, easily visible, hostile variants."

## Key findings (read before the table)
1. **The AnF ("Animals & Friends") template makes ~73 harmless-looking tiny animals player-hostile** — mice, hamsters, lemmings, hedgehogs, stoats, squirrels, geckos, newts, toads, caterpillars, slugs, earthworms, clams, scallops, starfish, sea urchins, flies, lobster. Mechanism (numbers from `pw_menagerie/anf/insects/fly_fruit.json`, same in every AnF file): spawn adds `cyd_ulta:flee` (`behavior.avoid_mob_type`, priority 4, player within **3 blocks**, `remove_target: true`) → its `on_escape_event` fires `evt:become_calm_event` → that event **ADDS** `cyd_ulta:alert_for_attack_targets` (`nearest_attackable_target`, priority 7, player within 16, must_see) and nothing ever removes it. From then on the mob approaches the player to bite (`melee_attack` p8, `attack` **3** = 1.5 hearts), the flee (p4) takes over again within 3 blocks, and so on. Static model cannot say how often a bite lands at this size — witness question. Side bug: `minecraft:angry`'s `calm_event` names `become_calm_event` (no `evt:` prefix) → event does not exist.
2. **Every AnF animal (even ladybugs, butterflies, robins, tits) carries `attack` 3** + `hurt_by_target` → a hit butterfly fights back for 1.5 hearts. Already "neutral" under the ruling; damage realism is a ruling question.
3. **Side finding — size law v2 did not land on 33 mobs** (all WA / WWA / YSav / YTri ports whose adult has NO `minecraft:scale` component): the plan's factor was applied to the baby group only (e.g. `pw:rat_wa` baby 0.095 = 0.5 × 0.19) and the adult stayed 1.0. In this census: `pw:crab_wa`, `pw:hedgehog_wa`, `pw:rat_wa` (e.g. WA rat is **1.63 blk long** now; v2 target 0.31). Full list in §E. Not part of this ruling — logged for the size workstream.
4. `pw:centipede_desert_anf` was skipped by size law v2 (client-entity parse error) and is still **1.86 blk long** at BP scale 0.75 (real desert centipede ≈ 0.2 m).
5. sf_nba scorpion poison is **script-applied** (`scripts/entity/Scorpion.js`, poison 6 s, keyed on a hard-coded typeId list) — a giant scorpion needs its id added there; removing the player target from the small ones keeps the script harmless (it only fires on a hit).

## Notes

### §A Class definitions (how each class was decided — static event-graph trace)
- **HOSTILE** — a `nearest_attackable_target` whose filter includes `player` sits in base components or in a group added on `minecraft:entity_spawned` / `ageable_grow_up` / `entity_transformed`, plus an attack behaviour (`melee_attack`, `leap_at_target`, `stomp_attack`) and `minecraft:attack`.
- **HOSTILE (in darkness / player in water)** — as above, with a filter condition (`is_brightness` < 0.49; player `in_water`).
- **HOSTILE-AFTER-FLEE** — player target group reachable only through `avoid_mob_type.on_escape_event` (AnF loop, finding 1). In play this is effectively hostile.
- **NEUTRAL-PROTECTIVE** — WA polar-bear copy: a BABY that sees a player broadcasts anger (41 blocks); adults then stomp-attack (6). No player target on adults.
- **NEUTRAL (vanilla bee)** — player target only after the engine fires `hive_destroyed` / `exited_disturbed_hive`, plus `hurt_by_target`.
- **NEUTRAL-RETALIATES** — no player target anywhere; `behavior.hurt_by_target` + melee. Some also hunt other mobs (noted).
