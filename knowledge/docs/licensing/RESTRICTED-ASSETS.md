# RESTRICTED ASSETS — swap list for a possible later release

Kept by Abs0lum's ruling (2026-09-30 11:37): personal-use assets go **straight into the main packs**; this list records every asset whose licence would NOT allow a release, so it can be swapped for a purchased (or CC0 / own) texture if he ever decides to release. Copies: his Google Drive (`AR-Licensing/RESTRICTED-ASSETS.md`) and the workspace (`_docs/licensing/RESTRICTED-ASSETS.md`); Claude updates both in the same build that uses a new restricted asset.

**Restricted** = any source that is not CC0 / public domain with redistribution allowed (see `TEXTURE-SOURCES-2026-09-30.md`): 3D Jungle (grants no licence; stand-in until he buys his own), AITextured (no redistribution of raw files), ShareTextures (no redistribution in collections without written OK), FreePBR (non-commercial; $19 commercial), Textures.com (no texture packs, even modified), CGAxis (games only in a proprietary format), Texturing.xyz (no texture packs), RenderHub (per-asset paid licence), Medievalism v7 (never distributable), third-party add-on assets, anything with no stated licence.

**Not restricted** (no swap needed): ambientCG, Poly Haven, TextureCan, 3DTextures.me (CC0, redistribution in projects stated), Patrix Java source (FreshLX permission), Mojang vanilla files inside Minecraft packs, textures Claude generates (recipe recorded), Abs0lum's own photos.

## How a swap will be bought (per asset, at swap time)
1. **Find the true owner** (needed for 3D Jungle, whose site says it does not own its textures): reverse image search the source texture (Google Lens, TinEye); record the original site / author here.
2. **Buy a licence that covers a resource pack other players download** — read the store's licence text first; most stock texture stores forbid texture / resource packs even when modified (Textures.com, Texturing.xyz, CGAxis, Poliigon said so on 2026-09-30; Adobe Substance 3D Assets = maybe: allowed only modified into a larger original work, not extractable stand-alone — ask Adobe first).
3. Routes that normally CAN cover it: a CC0 replacement (free: ambientCG, Poly Haven, TextureCan, 3DTextures.me); a written licence from the original author; a commissioned texture with the rights transferred; his own photographs.
4. Replace the file, re-run the pack's gates, move the line below to "Swapped".
