# p17 install — phone hosts, PS5 joins

**On the phone:**
1. Open the gofile folder link and download the 4 files:
   - `BP-02-AbsolutRealism-Tectonic-BP-v1_3_198.mcpack`
   - `RP-01-AbsolutRealism-Tectonic-RP-v1_3_106` → **v1_3_107**
   - `PW-TestRunner-BP-v0_5_3.mcpack`
   - `PW-TestRunner-RP-v0_6_0.mcpack`
2. Tap each one so Minecraft imports it.
3. Make a COPY of the test world and edit the copy:
   - **Behavior Packs:**
     - BP-02 v1.3.197 off, v1.3.198 on.
     - TestRunner BP v0.5.2 off, v0.5.3 on, at the bottom.
   - **Resource Packs:**
     - RP-01 v1.3.106 off, v1.3.107 on.
     - TestRunner RP v0.5.0 off, v0.6.0 on, at the top.
   - BP-02 and RP-01 are always swapped together.
4. Experimental toggles stay on. Host the world.

**On the PS5:**
- Join the phone's game. Turn Vibrant Visuals on.

**In game:**
- Type `/scriptevent pw:test start p17`.
- Notes now have 3 boxes; they join together.
