## What the port tool must fix (found by the dry run)

- Dead references inside the add-ons (the game skips them today): YTri 94 x `loot_tables/give/trial_medalha.json`, 43 animations
  that exist nowhere (e.g. `animation.elefante.baby_transform`), WA 24, JP 21 (`look_around`). Port drops them, logs each.
- Vanilla references (vanilla loot tables, `controller.render.dolphin`, `animation.cow.setup` …): kept — the game provides them.
- No BP file: WWA bombardier_beetle + 2 more, WA hyenas_2 -> client-only; we write a minimal behaviour (or skip, his call).
- YSav uses Worldy Library's `worldy:transformer_entity` (3 places): replaced by a plain event; Worldy itself is NOT stacked
  (its BP overrides vanilla fox / frog / ravager).
- AnF drops + field-guide menu run on @minecraft/server 1.8.0 with `world.beforeEvents.worldInitialize` (gone in 2.x): drops are
  rewritten into loot tables; the menu stays out unless he wants it.
- WWA BP overrides `villager_v2`: never copied.
- Ids: every ported creature gets `pw:<animal>` (Q2), spawn eggs + names in our lang files, spawn rules mapped to our biomes.
