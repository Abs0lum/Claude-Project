Note 1:
The instructions herein are made obsolete by the addition of support for Respackopts.
Download from https://modrinth.com/mod/respackopts and use the gizmo in the resource pack selection screen.
(you can still use the manual method described below, if you really want to)

Note 2:
If you're using Celestial 2.0 to use the pack, you may still use the manual method below, as with Respackopts,
the in-game chat will spew out errors from Celestial if you disable any features. This does not break the
pack in any way, it will still work perfectly fine, but in case that bothers you, do it manually.
-----------------------------------------------------------------------------------------------------------
Nuit:
Overworld sky directory: assets\nuit\sky\overworld\
End sky directory: assets\nuit\sky\the_end\
Delete the json file for the corresponding feature that you wish to remove.

Celestial:
Overworld sky: assets\celestial\sky\overworld\sky.json
End sky: assets\celestial\sky\the_end\sky.json
Nether sky: assets\celestial\sky\the_nether\sky.json
Open the json file, and delete the full quoted line along with the comma from "sky_objects", that you wish to remove.
(Make sure each sky object remains separated by a comma, otherwise the file will break. The last line must not have a comma after it!)
